## OWASP Top 10 (2021) — Systematische Prüfung

### 1. Broken Access Control
- **Status:** ✅ Kein Risiko
- Keine Admin-Funktionen, keine User-Rollen
- API ist public (Score-Submit für alle)
- S8.5 Anti-Cheat verhindert Score-Fälschung

### 2. Cryptographic Failures
- **Status:** ✅ Kein Risiko
- TLS 1.2/1.3 via Let's Encrypt ✅
- Keine sensiblen Daten verschlüsselt (keine Passwords, keine PII)
- localStorage enthält nur Player-ID + Name (nicht sensibel)

### 3. Injection
- **Status:** ✅ Geschützt
- SQL Injection: Prisma ORM parametrisiert ✅
- Command Injection: Keine exec/spawn calls ✅
- NoSQL Injection: Nicht verwendet (SQL only)

### 4. Insecure Design
- **Status:** ✅ Reviewd (S8.1 Threat Model)
- Architektur dokumentiert
- Threat Modeling (STRIDE) abgeschlossen
- Anti-Cheat implementiert (S8.5)

### 5. Security Misconfiguration
- **Status:** ✅ Gut konfiguriert
- nginx: HSTS, CSP, X-Frame-Options, X-Content-Type-Options ✅
- UFW Firewall: nur ssh/80/443 ✅
- Fail2ban aktiv ✅
- systemd Hardening (NoNewPrivileges, ProtectHome, etc.) ✅
- Default Site entfernt ✅
- Production mode (keine Stacktraces) ✅

### 6. Vulnerable Components
- **Status:** ⚠️ Teilweise (S8.3)
- 5 production-vulnerabilities in transitiven Dependencies
- Alle in Framework-Dependencies (Prisma, Next.js, Tailwind)
- Warten auf Framework-Updates
- 7 ungenutzte Dependencies entfernt (S8.3)

### 7. Identification and Authentication Failures
- **Status:** ✅ N/A (S8.6)
- Keine Authentifizierung (bewusste Entscheidung)
- S8.6 Evaluierung dokumentiert

### 8. Software and Data Integrity Failures
- **Status:** ✅ Geschützt
- CI/CD via GitHub Actions (S8.12 geplant)
- Dependencies aus package-lock (frozen)
- Keine unsigned Updates

### 9. Security Logging and Monitoring Failures
- **Status:** ⚠️ Verbesserungsbedarf
- Aktuell: console.error + journalctl
- Geplant: Structured Logging + Uptime Kuma (S8.9)
- API-Errors werden geloggt (try/catch)

### 10. Server-Side Request Forgery (SSRF)
- **Status:** ✅ Kein Risiko
- Keine Server-Side Requests außer fetch für Musik
- Keine URL-Input-Felder die Server-Requests auslösen
