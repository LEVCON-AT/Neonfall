## 3. Vibration Fix

**Problem:** Vibration in PWA-App funktioniert nicht.

**Ursache:** `navigator.vibrate` wird nur auf Android unterstützt. iOS Safari/PWA hat keine Vibration API. Code war korrekt aber nicht robust genug (kein try/catch).

**Fix:**
- `try/catch` um `nav.vibrate()` Aufruf
- Typ-Annotation robuster (`Navigator & { vibrate?: ... }`)
- Kommentar dokumentiert: nur Android, iOS no-op
