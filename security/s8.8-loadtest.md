## 3. Findings

### Stärken
1. **API Reads (Leaderboard):** Skaliert hervorragend — 500 concurrent mit P95 < 2s ✅
2. **Rate-Limiting:** Funktioniert einwandreich — 6/min/IP wird durchgesetzt ✅
3. **Server-Stabilität:** Server überlebt alle Last-Levels ohne Absturz ✅
4. **Keine Memory Leaks:** Server lief nach allen Tests normal weiter ✅

### Schwächen (Dev-Server spezifisch)
1. **Page Load langsam:** Dev-Server kompiliert on-the-fly → 3-8s bei hoher Last
2. **Timeouts bei 500:** 33% Timeouts bei 500 concurrent page loads (10s timeout)
3. **Produktion wäre 10x schneller:** Standalone build hat keine Kompilierung

### Breakpoint
- **API:** >500 concurrent (P95 = 2s Grenze)
- **Page:** ~200 concurrent (Dev-Server), ~2000+ (Production estimated)
- **Rate-Limit:** 6/min/IP (bewusst, nicht ein Engpass)
