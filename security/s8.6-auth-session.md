NEONFALL ist ein Browser-Spiel ohne sensible Daten. S8.5 Anti-Cheat (Score-Plausibilitätscheck) reicht für Leaderboard-Integrität. Echte Auth (NextAuth.js) kann später hinzugefügt werden wenn Account-Features gewünscht.

- Player-ID HMAC: verworfen (ohne echte Auth nutzlos)
- Multiplayer Auth: verworfen (1v1 invite-based, Rate-Limiting reicht)
- Beibehalten: Anonymous Player-ID in localStorage + S8.5 Anti-Cheat

Zukunft: NextAuth.js mit Email/Password oder GitHub OAuth falls Account-Features gewünscht.
